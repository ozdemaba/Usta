# Phase Gates

A phase is **complete** only when all gates pass.

- [ ] Scope and acceptance criteria recorded
- [ ] Source code implemented
- [ ] Security review completed for changed attack surfaces
- [ ] Static validation passes
- [ ] Automated tests pass
- [ ] Database migrations are idempotent and reversible where applicable
- [ ] Release manifest generated
- [ ] Deployment package generated and checksummed
- [ ] Target environment health check passes
- [ ] Regression checks pass
- [ ] Audit record exists

A failed gate blocks the next phase. No manual upload is treated as a substitute for the release pipeline.
